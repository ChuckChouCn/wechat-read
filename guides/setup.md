# 首次使用 / 环境引导

## 第 0 步：确认装了

`wechat-read.cmd` 应该就在 `SKILL.md` 旁边。先确认它在：

```bat
& "<SKILL_DIR>\wechat-read.cmd" status
```

- **能跑** → 往下走
- **文件不存在** → 还没装。让用户在**项目目录**里执行：

  ```powershell
  .\install.ps1
  ```

  它会找 Python、把项目复制到用户的 skills 目录、装依赖。
  **不碰 PATH**，装卸都只是文件夹的事。

> 命令写法：`<SKILL_DIR>` = 你读到 `SKILL.md` 时用的那个目录。
> 下面的示例为简洁都写成 `wechat-read <参数>`，实际执行时用上面的绝对路径。

## 第 1 步：先确认状态

```bat
wechat-read status
```

看 `ready` 字段：

- `true` → 一切就绪，继续正常操作
- `false` → 看 `hint` 字段，里面写了该做什么

## 第 2 步：没有数据目录时

先自动找（通常 1 秒内出结果）：

```bat
wechat-read detect
```

它读微信自己的配置来定位 —— **任何装了微信的机器都能读**，不依赖固定路径。
先告诉用户"正在查找，稍等"。

如果没找到，**再问用户**："你知道微信的数据目录在哪吗？" 知道就直接用。

用户也不知道，才试深度扫描：

```bat
wechat-read detect --deep
```

**这会深扫各盘符，可能要几分钟 —— 先提醒用户**，别不吭声地卡着。

> 不要为了找目录自己去递归遍历 C 盘 / D 盘，直接用上面的命令或问用户。

## 第 3 步：首次初始化

```bat
wechat-read init
```

**这一句是重点，要跟用户说清楚：**

> 这是**第一次使用才需要**的步骤。它会从正在运行的微信进程内存里读出
> 解密密钥，存到本机 `%USERPROFILE%\.weixin-read\keys.json`。
> **以后都不用再做**，不用每次跑。
> 只有微信换了账号、或清了聊天数据之后，才需要重来一次（那时加 `--force`）。

耗时通常 2-5 秒。因为要扫描微信进程内存，**提前告诉用户可能要等几秒**。

如果报权限错误，提示用户用**管理员权限**重开终端再试。

## 第 4 步：让用户看到成果

```bat
wechat-read sessions --limit 5
```

列出最近的聊天，就告诉用户"装好了，以后可以直接让我总结微信消息"。

## 什么时候需要重新初始化

| 情况 | 怎么办 |
|---|---|
| 第一次用 | `init` |
| 微信换了账号，或清了聊天数据 | `init --force` |
| 微信更新后报错 | 先试 `init --force` |
| 不确定当前状态 | `status`，它会告诉你该做什么 |

`status` 会明确说明密钥状态和下一步命令，不需要自己猜。

## 沟通要求

- **每步先说"做什么、要多久"，再动手**。用户看不到底层在跑什么，
  不说明就会出现"是不是卡死了"的疑虑。
- 涉及等待（首次初始化、`detect --deep`、解密大库）都要**提前打招呼**。
- 报错翻译成人话，附上下一步该做什么，而不是贴原始堆栈。

## 密钥与数据位置

| 东西 | 位置 |
|---|---|
| 解密密钥 | `%USERPROFILE%\.weixin-read\keys.json` |
| 摘要缓存（增量用） | `%USERPROFILE%\.weixin-read\summaries.json` |
| 程序本体 | 本 Skill 目录（`SKILL.md` 旁边） |

两个状态文件都在用户目录，不随项目目录走 —— 所以项目的移动不影响它们。

> 密钥能解密全部聊天记录，**不要分享、不要提交到 git、不要放进网盘同步目录**。
